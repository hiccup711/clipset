# 记录优先的界面调整

## 当前方案 · 0.2.6

剪贴板记录为主视觉，导航、搜索、品牌及操作控件保持紧凑。沿用 60px 窄侧栏、66px 顶栏、可滚动记录区和固定底栏，不增加信息面板。

### 配色与文字

- 主背景 `#ffffff`，侧栏 `#f6f8fc`，正文 `#202733`，辅助文字 `#737e90`。
- 强调色 `#2463eb`，选中记录背景 `#edf4ff`，细边框 `#c6d9ff`；悬停使用浅灰底。
- 正文统一为系统字体、16px、500 字重、24px 行距。展开只取消截断，字号、字重、颜色和原始换行保持一致。
- 来源与时间为 12px，标题为 18px。文案使用中性功能描述。

### 图标与控件

Lucide 线形图标保持统一比例，无类型图标底板；链接/图像用蓝色、文件用浅棕色、终端用紫灰色。收藏以琥珀色标识。菜单栏继续使用用户确认的纯白、透明背景双层纸张图标。

搜索框使用浅灰底，聚焦显示蓝色细边框。复制按钮为中性描边，粘贴按钮为浅蓝底。设置抽屉和确认框沿用同一套颜色及边框规则。删除按钮在悬停或键盘聚焦时显示。

### 本轮验证

在浏览器示例数据中检查 1000×700 和 macOS 最小窗口 680×480：搜索结果、分类、展开/收起、设置滚动和固定保存按钮、清空确认框显示正常，无横向溢出。展开前后的正文计算样式一致，浏览器无应用警告或错误；现有 10 项前端测试通过。

本轮只调整界面及版本标识；未重新测试系统全局监听或跨应用粘贴。辅助功能授权按用户要求清除，双击快捷键问题暂缓。
