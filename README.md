# Clipset

独立的 macOS 剪贴板工具。Rust + Tauri 2 负责本地存储与系统能力，React + TypeScript 负责界面。支持 macOS 12 及以上。

界面以剪贴板记录为主：60px 浅灰绿图标导航、宽幅内容列表、紧凑的顶部搜索与底部操作栏。记录正文与摘要保持清晰，来源、时间、品牌及辅助操作降低视觉权重。界面文案只描述功能、状态和操作结果。用户提供的 uTools 截图用作功能参考；产品行为参考 [Maccy](https://maccy.app) 的键盘操作和本地历史，以及 [Paste](https://pasteapp.io) 的搜索、预览与收藏。

## 已实现

- 默认 `⌘⇧V` 全局调起 / 收起，可在设置中录入新快捷键；冲突时保留原设置并提示。
- 支持“双击按键”调起：Space、Command、Control、Option、Caps Lock。可从列表选择或连续按两次录入；双击模式排除字母、Esc、退格键及其他未列出的按键。
- 记录文本、图片、文件引用；每 500 ms 检查系统剪贴板的变更计数。相同内容去重并更新到最近位置。
- 全部 / 文本 / 图像 / 文件 / 收藏分类，按内容、文件名和来源应用搜索。
- 长文本展开、图片缩略图与完整预览，记录显示复制时间、来源、字符数或图片尺寸。
- 复制到系统剪贴板；或恢复上一个应用并执行粘贴。回车和鼠标双击的行为分别设置。
- 单条删除；确认后全部清空（包括收藏）；收藏、暂停记录和历史数量上限。
- 菜单栏驻留、单实例启动；窗口不置顶，点击 X 或关闭窗口后隐藏到菜单栏并继续记录。只有菜单栏“退出 Clipset”才主动退出。
- 本地 SQLite 持久化，没有账号、云同步、遥测或运行时联网功能。

文本按纯文本保存。图片转为 PNG，单条不超过 16 MB、宽高各不超过 10,000 像素。文件只保存 URL 引用，不备份文件；原文件移动或删除后会提示无法复制。

不记录标记为 Concealed、Transient、AutoGenerated 或 1Password 的剪贴板内容。没有这些标记的普通文本会正常记录；目前没有按应用排除功能。启动前的剪贴板和暂停期间的内容不会补录。

## 开发

需要 Node.js 20.19+、Rust 1.88+、Xcode Command Line Tools。

```bash
npm ci
npm run tauri dev
```

仅预览前端：

```bash
npm run dev
```

浏览器预览会明确显示提示，只在点击“载入示例”时显示测试记录，不模拟系统监听、全局快捷键或跨应用粘贴。关闭或刷新页面会重置示例。

## 构建本地应用

```bash
npm run tauri build -- --bundles app
```

产物：`src-tauri/target/release/bundle/macos/Clipset.app`。需要安装包时使用 `npm run tauri build -- --bundles app,dmg`；DMG 位于 `src-tauri/target/release/bundle/dmg/`。构建的是当前 Mac 架构；本次验证环境为 Apple Silicon。

应用包继续使用本地 ad-hoc 临时签名（`signingIdentity: "-"`），不使用开发证书、不访问证书私钥，也不进行公证。bundle identifier 为 `app.copyy.desktop`。

临时签名的授权身份依赖构建内容，重新打包后可能需要重新添加辅助功能授权。安装到固定位置后只运行该副本，不要混用 DMG 内应用、debug 二进制和构建目录产物。当前按用户要求保留此打包方式。

## GitHub 自动发布

工作流：`.github/workflows/release.yml`。推送 `v*` 标签后，GitHub Actions 会检查版本号、执行前端/Rust/原生桥接测试与 Clippy，分别在 Apple Silicon 和 Intel macOS runner 上构建 DMG 及 `.app.zip`。只有两个架构全部成功，才上传完整附件和 SHA-256 校验文件并发布 Release。使用 GitHub 自带的 `GITHUB_TOKEN`，无需配置 Apple 证书或公证密钥。

发布前同步 `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`、`src-tauri/tauri.conf.json` 和设置页中的版本号。然后执行（以 0.2.9 为例）：

```bash
node scripts/check-release-version.mjs v0.2.9
git add .
git commit -m "Release 0.2.9"
git push origin main
git tag v0.2.9
git push origin v0.2.9
```

也可以在 GitHub 的 **Actions → macOS Release → Run workflow** 手动检查并构建；从分支手动运行只生成 Actions artifacts，不发布 Release。标签运行失败时可在 Actions 重新运行，未发布的草稿会被续传；已经发布的版本不会被覆盖，应使用新版本标签。

安装包下载入口：[GitHub Releases](https://github.com/hiccup711/clipset/releases)。`aarch64` 适用于 M 系列 Mac，`x64` 适用于 Intel Mac。安装包沿用临时签名，首次打开及更新后的辅助功能权限按上文处理。

## 使用

1. 启动 Clipset，在其他应用里正常复制内容。
2. 在目标输入位置放置光标，按 `⌘⇧V` 调起窗口。
3. 搜索并用上下方向键选择，回车或双击按设置执行复制 / 粘贴。
4. 底部“复制”按钮始终只复制，“粘贴到原应用”按钮尝试恢复原应用并粘贴。
5. `⌘K` 聚焦搜索，`Esc` 先清空搜索，再次按下收起窗口。列表获得焦点时 `⌘⌫` 删除选中记录。

双击快捷键在 **偏好设置 → 全局调起方式 → 双击按键** 配置。要求在 450 毫秒内连续按下并松开同一个物理键两次；左右修饰键均可使用，但一次双击不能混用左右两侧。长按连发、超时、其他键或组合键介入会重置识别。Caps Lock 按 macOS 发出的两次锁定状态变化识别。

全局双击监听需要辅助功能权限。0.2.1 起，权限缺失时仍保存设置，并在保存按钮上方显示“已保存，等待授权”及授权入口；授权后自动启用双击监听。本次运行中已注册的旧快捷键保留到新快捷键可用为止。注册冲突或数据库写入失败会明确提示，不冒充成功。监听不拦截按键，因此 Space 可能在当前输入位置输入空格，Caps Lock 保留系统大小写或输入法切换行为；系统重映射影响实际收到的键事件。设置窗口可见且获得焦点时暂停快捷键触发，隐藏窗口时立即清除暂停状态。

直接粘贴需要在 **系统设置 → 隐私与安全性 → 辅助功能** 为 Clipset 授权。设置抽屉可打开对应页面并检查状态；只复制不需要此权限。开发版与构建产物可能需要分别授权。若系统开关已开启、应用内仍显示未授权，请移除旧的 Clipset 条目，通过“＋”选择当前构建的 `Clipset.app`，开启后重新启动应用；以应用内的实际权限检查为准。若重新添加后仍不生效，可先完整退出 Clipset，再运行 `tccutil reset Accessibility app.copyy.desktop`，仅清除本应用的旧授权，然后重新添加当前应用并开启；不要重置全部应用权限。

粘贴会检查原应用是否仍存在，等待该应用成为前台且快捷键修饰键松开，再发送 `⌘V`。权限不足时不会冒充成功；原应用无法恢复时保留已复制内容并提示手动粘贴。目标应用是否接受该类型仍由该应用决定。

0.2.2 修正了菜单栏应用的启动配置：应用包声明 `LSUIElement=true`，并在 Tauri setup 中通过 `AppHandle` 设置运行时 `Accessory` 模式，避免调用仅修改启动参数的 `App` 方法。窗口显示或隐藏均不应占用 Dock 的运行应用位置；右上角菜单栏图标用于重新打开与退出。

## 本地数据

`~/Library/Application Support/app.copyy.desktop/history.sqlite3`

为沿用已有记录与设置，改名后保留 bundle identifier `app.copyy.desktop` 和内部 Rust crate 名称 `copyy`。

数据库保存在当前用户可访问的目录内，内容未加密。默认保留 500 条非收藏记录，可选 100 / 500 / 1,000 / 5,000 条。内容预算 128 MB，超出后从最早的非收藏记录开始清理；收藏最多 100 条且不自动清除，因此收藏本身可能令总量超过预算。删除记录不会删除原文件，也不会清空系统剪贴板。

## 检查

```bash
npm test
npm run build
npm run test:rust
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
npm run test:native
npm run test:shortcuts
```

`test:native` 在 macOS 上直接测试 AppKit 剪贴板桥接。它临时使用剪贴板，在内存中保留原内容并在结束时恢复；若期间剪贴板被外部更改则不覆盖。它不申请辅助功能权限，也不发送按键。

`test:shortcuts` 在进程内构造 AppKit 键事件，验证左右修饰键、Caps Lock、Space 与自动重复的解析，不发送系统按键、不申请权限。

已验证：

- Rust：去重且保留收藏、自动清理、全量清空、字面搜索、中文文件名搜索、设置及历史持久化。
- TypeScript：组合键录入使用物理按键标识；双击录入仅接受五类按键，并排除字母、长按连发、超时、夹杂其他按键及左右混用。
- 双击监听：Rust 状态机测试及 AppKit 事件解析测试通过；浏览器已验证双击 Space 录入、字母排除、Caps Lock 选择保存与重新打开。
- 设置反馈回归：待授权时保留保存结果并提供入口；保存失败时提示在固定底部显示；成功启用后才关闭设置抽屉。
- AppKit：Unicode 文本、PNG 读写与缩略图、文件 URL 往返、忽略私密标记、缺失文件时保留现有剪贴板。
- 内置浏览器：搜索、分类、展开、收藏、设置保存、清空确认、空状态；1000 × 700 主窗口和窄窗口检查；无控制台错误。
- 0.2.2：应用包签名及资源封装检查通过，`LSUIElement=true`；实际运行进程为 `Accessory` 模式，用户确认关闭后不再出现在 Dock。已验证 `⌘⇧V` 从 Finder 调起隐藏窗口。系统 TCC 日志证实旧签名授权与当前构建不匹配；仅重置本应用的辅助功能授权并重新添加当前应用后，设置页显示“辅助功能已授权”，保存“双击 Option”成功，用户实际按键确认能从其他应用调起隐藏窗口。
- 桌面端：应用启动、真实记录捕获、已有实例重新调起。0.2.1 已实测将 `DoubleTap:Option` 保存到实际数据库；未授权提示在底部可见；点击主窗口 X 后原 PID 保持运行，再打开应用仍使用同一 PID。

尚未完成：授权后的跨应用粘贴端到端验证、其余四类双击按键的全局实机验证、Intel Mac 与 macOS 12 实机验证。原生事件解析测试不等同于真实按键端到端验证。

## 代码位置

- `src/components/`：侧边导航、列表项、底部操作栏、设置抽屉、确认框。
- `src/bridge.ts`：Tauri IPC 与明确区分的浏览器预览。
- `src-tauri/src/store.rs`：SQLite、去重、搜索、保存与清理。
- `src-tauri/src/lib.rs`：命令、全局快捷键、菜单栏、监听与粘贴流程。
- `src-tauri/native/clipboard.m`：小型 AppKit / ApplicationServices 桥接，用于 macOS 剪贴板类型、原应用激活与权限检查。
- `src-tauri/src/shortcut.rs`、`src-tauri/native/shortcuts.m`：快捷键校验、双击状态机与 macOS 键盘事件监听。
- `docs/design/`：Clipset 独立视觉方案与设计检查记录。

### 0.2.3 菜单栏位置修复

在带刘海的 MacBook 上，菜单栏右侧图标过多时，新建状态栏项默认排到最左侧，可能落在刘海的不可见区域，即使系统的“允许在菜单栏显示”已开启。Clipset 现在为状态栏项设置固定的 `autosaveName`，并注册靠近右侧的初始位置；AppKit 会保存用户之后通过 ⌘ 拖动选择的位置。初始值通过 `registerDefaults` 提供，不覆盖已有的位置偏好。

本机原生诊断：屏幕右侧安全区从 x=956 开始；默认新图标位于 x=750，设置初始位置后移至 x=1503，在 Siri 与控制中心之间可见。此诊断进程不读取剪贴板，验证后已清理。

0.2.3 打包后验证：关闭主窗口，进程保持 `Accessory` 模式且没有主窗口显示，剪贴板图标仍在 Siri 与控制中心之间可见。Rust 9 项测试、Clippy、前端构建及 macOS 应用打包通过。

### 0.2.8 列表键盘导航与焦点边框

方向键的自动重复事件现在持续更新选中项，并阻止浏览器默认滚动；选中状态提交后将该项滚入可视区域。回车、复制、删除等操作仍过滤重复事件。列表焦点边框移到独立的固定覆盖层，滚动图片不会遮住边框，覆盖层不拦截鼠标操作。

验证：14 项前端测试通过，包含重复方向键、批量状态更新、首尾边界、输入法合成和弹窗隔离；浏览器在 1000×700 和 680×480 下检查图片滚过底边及选中项可见性，无应用控制台错误。系统原生长按尚需安装后实测。
